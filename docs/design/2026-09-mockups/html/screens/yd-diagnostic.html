What is kept, and where
Each entry is a time, a level, a short tag and a message. The newest 200 are kept; on the Android app its own log joins them.
Content URIs, file paths and web query strings are blanked out before an entry is kept.
They live in memory only and are gone when the app restarts. They leave the app only inside an Export you make.
